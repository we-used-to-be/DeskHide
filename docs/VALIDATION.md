| 启动空闲总工作集 | 33,112,064 字节（31.58 MiB） | 11,616,256 字节（11.08 MiB） |

| 5 个空闲样本的 CPU 增量 | 0 秒 | 0 秒 |

两版分别启动后等待 8 秒、每秒采样 5 次。未调用工作集修剪、未强制 GC；这是一轮启动空闲比较，不是长时间稳定性统计。原始数据为 `artifacts/reference-baseline.json`、`artifacts/native-idle.json`。

**使用后会加载 Windows Shell/MSAA COM 模块，因此不能把 11.08 MiB 当作使用后的上限。** 用户运行版本的后续样本约 35.42 MiB 总工作集、10.30 MiB 私有提交；缺少参考版相同操作后的样本，不据此声称使用后内存降低多少。用户任务管理器截图显示桌隐为 7.6 MB，属于任务管理器展示口径；不应与总工作集或私有提交直接比较。

截图中的 `桌面窗口管理器` 是 Windows `dwm.exe`，其 107.1 MB 不能计入桌隐。安装包约 2 MiB 的主要固定成本来自 Inno Setup，用户已明确接受当前体积。

## 人工验收清单

1. 双击图标与其文字：文件正常打开，图标不隐藏；普通窗口、任务栏、桌面菜单点击不切换。
2. 托盘手动切换、暂停/恢复、关于、退出；暂停时桌面双击不切换。
3. 安装版默认不开机启动，勾选托盘自启动后注销/登录能启动，取消后不启动；卸载后本应用启动值清理。
4. 如使用多屏，测试副屏空白、负坐标、不同 DPI；如交换主鼠标键，测试系统主键双击。
5. 保存工作后自行重启 Explorer：图标显隐状态保留，托盘重新出现，双击继续工作。
